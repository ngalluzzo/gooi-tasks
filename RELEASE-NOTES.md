First public early-access release of Gooi Tasks for macOS Apple Silicon.

- Desktop `.mcpb` bundle: download, open in a compatible desktop host, review and install.
- Portable `.tar.gz`: standalone runtime and `--print-config` fallback for other local MCP hosts.
- Persistent local task board with shared assistant/UI operations and an included MCP Apps preview.
- Verified with the official MCPB unpacker/config resolver, a real MCP client outside the development repository, restart persistence, and the browser/AppBridge integration.

The bundle and binary are unsigned/not notarized. Host and OS policy may block installation. This is not a curated-directory listing, and automatic updates are not configured. Other desktop architectures have not been published or qualified. The current protocol/install tests do not claim a complete third-party host compatibility matrix.

Checksums and the release inventory accompany both downloads. Task data is stored outside the extension directory and survives uninstall until explicitly removed.
